# hello-world

**Tech Education Club**

Hi everybody!

I like to learn and share everything, anywhere, anytime.

## Giới thiệu

`hello-world` là kho lưu trữ khởi đầu của Tech Education Club, nơi các thành viên làm quen với Git và GitHub. Đây là nơi thử nghiệm các thao tác cơ bản: tạo nhánh, chỉnh sửa tệp, commit, mở pull request và hợp nhất thay đổi.

## Mục tiêu

- Làm quen với quy trình làm việc trên Git và GitHub.
- Thực hành cộng tác qua nhánh và pull request.
- Chia sẻ kiến thức công nghệ giữa các thành viên trong câu lạc bộ.

## Bắt đầu

Sao chép kho về máy:

```bash
git clone https://github.com/hieuanh2526/hello-world.git
cd hello-world
```

## Cách đóng góp

1. Tạo nhánh mới từ `master`: `git checkout -b ten-nhanh-cua-ban`
2. Thực hiện thay đổi và commit với thông điệp rõ ràng.
3. Đẩy nhánh lên GitHub: `git push -u origin ten-nhanh-cua-ban`
4. Mở pull request để các thành viên khác xem xét.

## Liên hệ

Mọi câu hỏi và góp ý, vui lòng mở một [issue](https://github.com/hieuanh2526/hello-world/issues) trên kho này.
