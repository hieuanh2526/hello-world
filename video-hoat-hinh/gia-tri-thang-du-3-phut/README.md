# Giá trị thặng dư – bản 3 phút (giọng thật)

4 phần, mỗi phần 45–60 giây, ghép thành một video khoảng 3 phút. Lời thoại đã duyệt nằm trong `loi-thoai/`.

| Phần | Nội dung | Hình |
|---|---|---|
| 1 | Mâu thuẫn của công thức chung T – H – T'; hàng hóa sức lao động: 2 điều kiện, 2 thuộc tính | vẽ mới |
| 2 | Bản chất giá trị thặng dư: c, v, ngày lao động, G = c + v + m, m' | dùng lại `../gia-tri-thang-du/` (bỏ 2 cảnh đầu) |
| 3 | Giá trị thặng dư tuyệt đối (150%), tương đối (300%), siêu ngạch | vẽ mới |
| 4 | Ý nghĩa: hòn đá tảng, quy luật tuyệt đối, lợi nhuận – lợi tức – địa tô, bản chất bóc lột; câu hỏi thảo luận | vẽ mới |

## Ghi âm

- Mac: QuickTime Player (File → New Audio Recording) hoặc app Ghi âm (Voice Memos); iPhone dùng Ghi âm cũng được.
- Phòng yên tĩnh, tắt quạt và điều hòa; mic cách miệng 20–30 cm.
- Mỗi phần một file: `phan-1.m4a`, `phan-2.m4a`, `phan-3.m4a`, `phan-4.m4a`; đầu và cuối để im khoảng 1 giây.
- Đọc đúng chữ trong `loi-thoai/phan-N.txt`, tốc độ giảng bài. Nhầm thì ghi lại cả phần.
- c, v, m đọc là «xê», «vê», «em»; T' đọc là «T phẩy».

Gửi file: kéo thả vào khung chat với Claude, hoặc chép vào `~/hello-world/ghi-am/` rồi:

```bash
cd ~/hello-world && git add ghi-am && git commit -m "Ghi âm 4 phần" && git push
```
